# 语义规格 · ops.memory.digest

> 七步流水线第 1 步：需求入账。挂语义层概念「会话摘要」。

## 条目

- **算子名**：ops.memory.digest
- **输入**：session_id（string）——待摘要会话标识
- **输出**：digest（string）——会话摘要文本；结构：结论一行 + 要点 ≤5 行
- **前置条件**：hub.ledger.read 可读；目标会话存在
- **副作用边界**：仅 hub.archive.append（摘要写回归一层）；禁止网络、禁止文件系统直写
- **风险级别**：低（查询只读类，设计稿灰度首选）
- **筛门**：hard + soft

## 验收口径

- 输入不存在会话 → 明确报错，不产出空摘要。
- 摘要不含密钥明文、不含个人敏感字段（硬筛门）。
- 产出必带算子版本号与指纹，可回溯。
